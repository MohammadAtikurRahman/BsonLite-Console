QUICK START

Run your app. Click Connect.

Use a BsonLite SDK with automatic Console discovery. Keep your existing app startup code: the SDK prepares a local connection automatically.

// Your existing application code stays the same.
const BsonLite = require('./BsonLite.cjs');
const database = await BsonLite.connect();

For single-file SDK apps, replace the old BsonLite.cjs with the supplied updated file and restart your app. For npm projects, run npm i bsonlite-sdk, then restart your app. If you already use an older BsonLite database, follow the migration guide before upgrading.

Open Console. Your database appears in the dropdown above and its URL is filled in. Click Connect. With multiple apps, choose the database you want from the dropdown. No helper installation, project-folder selection or pasted token is required.

No database found? Start the updated SDK app, leave it running, and use the same Windows account. A closed database cannot be discovered. You can still paste a direct mongodb://…, mongodb+srv://…, or a previous bsonlite://… app link.
